# GAi - Complete Project Documentation

## 🌟 Project Overview

**GAi** is a premium social networking and membership management platform featuring:
- Advanced biometric authentication (Voice & Facial Recognition)
- Exclusive service marketplace
- Secure instant messaging
- Multi-tier membership system (VIP, VVIP, Presidential)
- Geolocation-based services
- Comprehensive admin dashboard

---

## 📁 Project Structure

```
/src/app/
├── App.tsx                    # Main application entry with RouterProvider
├── routes.tsx                 # React Router configuration
│
├── pages/                     # All application pages
│   ├── Root.tsx              # Root layout with Toaster
│   ├── LandingPage.tsx       # Public landing page
│   ├── AuthPage.tsx          # Login/Registration with biometrics
│   ├── Dashboard.tsx         # Main user dashboard
│   ├── ServiceHub.tsx        # Browse and post services
│   ├── Messenger.tsx         # Instant messaging
│   ├── Profile.tsx           # User profile pages
│   ├── Subscription.tsx      # Membership plans
│   ├── AdminPanel.tsx        # Admin dashboard
│   └── NotFound.tsx          # 404 page
│
├── components/
│   ├── Navbar.tsx            # Main navigation component
│   └── ui/                   # Reusable UI components
│
└── data/
    └── mockData.ts           # Mock data (users, services, etc.)
```

## 🎯 Key Features

### 1. **Authentication System** (`/auth`)
- **Voice Recognition Login**: Simulated voice authentication
- **Facial Recognition Login**: Simulated facial scanning
- **Email/Password Login**: Traditional authentication
- **Registration**: Multi-step registration with biometric setup

### 2. **Dashboard** (`/dashboard`)
- Statistics overview (services, members, ratings)
- Trending services feed
- Activity timeline
- Quick actions panel
- Active members sidebar

### 3. **Service Hub** (`/services`)
- Browse verified services by category
- Filter by:
  - Category (Escort, Hostess, Model, Massage Therapist, etc.)
  - Location
  - Price range
- Post new services (with tier-based limits)
- Service details with ratings and reviews

### 4. **Instant Messenger** (`/messenger`)
- Contact-based messaging (privacy-first)
- Add contacts via Membership ID only
- Real-time messaging interface
- Message status indicators (sent/read)
- End-to-end encryption notice
- Disappearing messages support

### 5. **User Profiles** (`/profile/:id`)
- Profile information with verification badge
- Membership tier display
- Location and nationality
- Bio and expertise
- Service listings
- Photo/video portfolio
- Statistics (services, ratings, reviews)

### 6. **Subscription Management** (`/subscription`)
- Three membership tiers:
  - **VIP**: Basic features ($99/month)
  - **VVIP**: Advanced features ($199/month) - Most Popular
  - **Presidential**: Premium unlimited ($349/month)
- Flexible duration options:
  - Weekly, Monthly, 3/6/12 months
  - Discounts for longer commitments
- Feature comparison table
- FAQ section

### 7. **Admin Dashboard** (`/admin`)
- Platform statistics overview
- User management:
  - View all users
  - Verify users
  - Edit/delete users
- Service management:
  - Review services
  - Approve/reject listings
  - Edit/delete services
- Category management:
  - Add custom categories
  - Edit existing categories
- System settings:
  - Platform configuration
  - Security settings
  - Authentication methods

## 🎨 Design System

### Color Palette
- **Background**: Gradient from neutral-950 to neutral-900
- **Primary (Amber)**: 
  - Buttons: amber-500 to amber-600
  - Accents: amber-400
- **Membership Tiers**:
  - VIP: Blue (blue-500 to blue-700)
  - VVIP: Purple (purple-500 to purple-700)
  - Presidential: Amber/Gold (amber-500 to amber-700)

- System uses Tailwind CSS v4
- Default theme with custom tokens in `/src/styles/theme.css`

## 👥 User Roles & Permissions

### Members (All Tiers)
- Create and view profiles
- Browse services
- Message contacts
- Subscribe to membership plans

### VIP Members
- Post up to 3 services
- 10 portfolio photos
- Basic messaging
- Standard support

### VVIP Members
- Post up to 10 services
- 50 photos + 5 videos
- Priority listing
- Verified badge
- Advanced analytics
- Priority support

### Presidential Members
- Unlimited services
- Unlimited portfolio
- Top placement in searches
- Featured status
- 24/7 VIP support
- API access
- Custom category creation

### Administrators
- Full user management
- Service moderation
- Category management
- System configuration
- Analytics access

## 📊 Data Models

### User
```typescript
{
  id: string
  membershipId: string (e.g., "GAi001921")
  name: string
  email: string
  bio: string
  avatar: string
  nationality: string
  location: { city, country, coordinates }
  membershipTier: 'VIP' | 'VVIP' | 'Presidential'
  verified: boolean
  joinedDate: string
  portfolio: { photos[], videos[] }
  services: string[]
}
```

### Service
```typescript
{
  id: string
  userId: string
  userName: string
  membershipId: string
  category: string
  title: string
  description: string
  price: number
  currency: string
  location: string
  images: string[]
  verified: boolean
  rating: number
  reviewCount: number
  createdAt: string
}
```
